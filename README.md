# Earnings Call NLP Analysis

This repository contains two notebooks for analyzing corporate earnings call transcripts—measuring executive evasion, emotional tone.

## Notebooks

1. **`Earnings_Call_Demo_Dashboard_v7-1.ipynb`**  
   Parses earnings call transcripts into Q&A pairs, scores executive evasion (CrossEncoder + regex) and prepares the KPIs and RAG data for the dashboard.

2. **`Earnings_Call_Backtest.ipynb`**  
   Tests and benchmarks the custom evasion/tone signals on historical marcet data.
